[team-hippodrome/pokestadium](https://github.com/team-hippodrome/pokestadium), with the port's changes edited in
place (marked `PORT` where they are port-only).

Last synced with: `d67b0bcb4de8b047d3d7db2586c5792c5963a16a` (`master`, 2026-11-26)

To sync with a newer decomp commit, three-way merge the decomp's changes since the commit above into this directory,
then update the commit above. See docs/BUILDING.md, "The vendored game".
