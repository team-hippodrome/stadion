# Battle animation slots and scene rows the shipped data can select

Generated by `routes/battle_gates/anim_slots.py <cg_all4.json> <US ROM> <out>` from the battle engine's data (the effect scripts and slot tables in `battle_engine_315D50.c` / `battle_engine_347330.c`, the state-row table in `battle_engine_2F3CB0.c`, the per-species idle cue in the ROM at 0x70D3A0) and checked against the runs. The proof is the one the Game Boy music commands got from playing all 151 cries: every move's animation ran (the batch4 sweep, completed by single-move runs of 12, 60, 100, 154, 155 in `battle_gates`), every row index the code can pass is listed below, so a slot that no selectable list names is code the shipped data cannot run.

## How a slot is selected

`BattleAnim_RunEffectList(row, list, mode)` reads a byte list until a 0 and, for each byte s, calls `gMoveAnimEffectStartInitFuncs[s]`, `gMoveAnimEffectStartFuncs[s]` and registers `gMoveAnimEffectStartUpdateFuncs[s]` / `gMoveAnimEffectStartDrawFuncs[s]` (end lists: the four End tables).

| list | table | rows | rows the code can select | how |
|---|---|---|---|---|
| 0, 1 (start), 2 (end) | `gMoveAnimEffectScripts[move][0..2]` | 166 | all (the used move) | `BattleAnim_QueueMoveEffect*` with the move id |
| 3 (start) | `D_84386D44[row][0]` | 15 | [2, 3, 5, 6, 8, 10, 11, 12, 13] | literals of `BattleAnim_QueueEffectList3` [2, 3, 8, 10, 11, 12, 13]; modes [2, 5] of the entered state rows; the species idle cue: 6 (dex [128]); dynamic call sites: `BattleAnim_QueueEffectList3(move_id,`; `BattleAnim_QueueEffectList3(sCurrentAnimation->unk_05,` |
| 4 (start) | `gBattleAnimMode4StartEffectLists` | 12 | [1, 3, 4, 5, 6, 7, 8, 9, 10] | literals of `BattleAnim_QueueEffectList`; dynamic call sites: none |
| 6 (end) | `D_84386DEC` | 5 | [1, 2, 3] | literals of `BattleAnim_QueueEffectList6` (its other two callers, `BattleAnim_QueueEffectList5` / `BattleAnim_QueueEffectList6Alt`, have no caller); dynamic call sites: none |
| 9 (start) | `gBattleAnimMode9StartEffectLists` | 2 | both (counted) | particle descriptor field |

State rows (`sBattleSceneStateRowTable`, 22 rows) are entered only by `BattleScene_EnterStateRow(pokemon, <literal>)`; the literals are [0, 1, 2, 3, 4, 8, 9, 11, 12, 13, 14, 15, 16, 17, 18, 19, 21], so rows [5, 6, 7, 10, 20] are never entered. The modes of entered rows feed list 3 (`BattleScene_QueueRowEffectList3`).

| | slots | named by a selectable list | never |
|---|---|---|---|
| start | 150 | 132 | 17 (slot 0 is the terminator) |
| end | 100 | 81 | 18 (slot 0 is the terminator) |

Slot bytes past a table: none. Lists that run past their own array: none. `gMoveAnimEffectStartInitFuncs` has 145 entries for 150 start slots: slots 145-149 have no init entry and no list names them.
